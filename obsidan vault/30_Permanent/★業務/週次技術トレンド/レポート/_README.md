# 週次技術トレンド レポート保存先

このフォルダに、週次調査の成果物を保存する。

## 命名規則

`週次技術トレンド_YYYYMMDD-YYYYMMDD.md`

- 開始日〜終了日は調査対象期間（通常は直近7日）
- 例：`週次技術トレンド_20260713-20260719.md`

## 運用

1. `../週次技術トレンド調査プロンプト.md` の貼り付けブロックを Cursor（Grok）に投げる
2. エージェントが本フォルダの直近レポートを参照し、重複を避けて調査
3. 新規レポートを本フォルダに保存する

過去レポートは削除せず蓄積し、週次の「新規性」チェックに使う。
