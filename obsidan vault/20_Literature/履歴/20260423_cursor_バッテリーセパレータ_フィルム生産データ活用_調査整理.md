## （2）フィルム生産技術 × データ活用 — 開発テーマ候補3件

「品質予測」だけに収束させず、**現場工学的メカニズム**と**データ拡張性**がセットになるテーマに絞る。週次で繰り返しやすい**新規性**の付け方としても利用可。

### テーマ1：非等温キャスティング／延伸＋ tenter 連成の「物理拡散モデル＋学習」ハイブリッド

| 項目 | 内容 |
|------|------|
| **① テーマ概要** | 薄膜キャスティングや延伸（バッテリーセパ、光学、包装の共通部）で、**厚み・幅・残応力**は多変数の時間発展。純粋なデータのみより、**物性（緩和時間等）**を特徴量に含めた ML が、**条件外挿**に強い。学術例として、**非等温粘弾性キャスティング**の ML 予測や、**押出デジタルツイン**最適化の枠組みが参照できる。 |
| **② どのようなデータを使うか** | ライン：温度、ポンプ速度、風、チルロール/プリヒート、クリップ張力、速度。品質：プロファイル厚み、幅、光学遅延、力学的試験。＋ 材料ロット物性（G'、分子量、添加剤）。可能なら **CFD/簡易1D+実測**で教師拡張。 |
| **③ 生産技術・品質・コストへの期待効果** | 立ち上がり・**ロット切替**の**試行減、歩留まり安定**、**エネルギー・溶剤/排熱**の最適。セパなら、**多孔性・針孔**とレシピの相関可視化。 |
| **④ 今後の展開余地** | PoC は**1ライン・1品番**の「**セッティング仮想試行**」。成功後、**多ライン**へは特徴量基準を揃えた**転移学習**。**横展開**は、双軸延伸や co-ex への同型フレーム。 |

### テーマ2：共押出・層厚比（界面）のリアルタイム監視と分岐クラスタ制御

| 項目 | 内容 |
|------|------|
| **① テーマ概要** | 多層膜・層圧分離が肝のプロセスでは、**層の厚み比**が品質の主成分になり得る。層分離・不連続を、**ライン上セグメントのクラスタリング**＋**LT比**系の指標で**閉ループ**に持ち込む発想（二層共押出等の**層均一性管理**に近い工学的イメージ）。高機能セパ、バリア、光学でも共通。 |
| **② どのようなデータを使うか** | スクリュー区間別の**温度/圧力/トルク**、ダイ圧、ライン各点厚み/β線、表面欠陥カメラ、**反応は遅延付き**でラベル。 |
| **③ 生産技術・品質・コストへの期待効果** | **層内欠陥・皺・界面不良**の早期抑止。スリット以降廃棄の削減。**コーティング前工程**の安定にも波及。 |
| **④ 今後の展開余地** | PoC は**厚み測定が既にある共押**から。拡張で**NIR/中赤外、音響、振動**を乗せた多モーダル。 |

### テーマ3：押出–スリット–巻取の「時系列＋表面画像」の自己教師 異常＆因果

| 項目 | 内容 |
|------|------|
| **① テーマ概要** | フィルムの欠陥は、**点欠陥**（孔、異物）と、**帯状・周方向モアレ**的な周期性の両方が出る。**画像のみ**と**DCS時系列のみ**のどちらか一方は誤警報が出やすい。押出**シミュレーション/ML による溶融品質**指標（文献領域）を上流に置き、**下流画像**で確証する**2段**の枠。 |
| **② どのようなデータを使うか** | ライン上：張力、速度、巻取径、展開、エッジ、各ロールの温度/振動。画像：面全体スキャン or 点検。ラベルは**欠陥クラス＋仮因**（巻取ズレ、粉塵、靜電、ニップ滑り）。自己教師（正常のみ）から開始可能。 |
| **③ 生産技術・品質・コストへの期待効果** | **クレーム歩合の削減、スリットロス低減、稼働率**。**原因候補の切り分け**が速くなり、熟練依存が下がる。 |
| **④ 今後の展開余地** | PoC は**欠陥頻度が中程度の1SKU**。正解ラベル少でも**自己教師＋アクティブラーニング**で拡張。**横展開**は、塗工・積層、電池用以外の**一般フィルム**にも可。 |
