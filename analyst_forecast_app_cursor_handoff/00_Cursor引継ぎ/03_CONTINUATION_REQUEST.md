# Cursor用・作業再開依頼文

## 使用場面

初回実装後、別セッションで作業を続けるときに使用します。

## コピペ用依頼文

```text
このリポジトリの「アナリスト予想検証アプリ」実装を続けてください。

最初に以下を確認してください。
- Git statusと現在の差分。
- docs/06_実装/IMPLEMENTATION_PLAN.md
- docs/06_実装/IMPLEMENTATION_STATUS.md
- docs/06_実装/IMPLEMENTATION_ASSUMPTIONS.md
- docs/05_計画/MVP_PLAN.md
- 00_Cursor引継ぎ/02_SPEC_AUTHORITY.md
- 00_Cursor引継ぎ/04_IMPLEMENTATION_ACCEPTANCE_CHECKLIST.md
- 既存テストの結果。

既に完了した処理を推測で作り直さず、コード、テスト、状態文書から確認してください。現在のMVPで未完了の項目から、依存関係を満たす次の一つの実装単位を選び、その理由と対象要件を短く示してから実装してください。

重大なブロッカーがなければ、質問だけで停止せず、実装、テスト、文書更新まで進めてください。仕様変更が必要な場合は勝手に確定せず、変更案と影響範囲を提示してください。原文不変、AI出力のPython検証、市場値の非推測、AI／Pythonの役割分担を維持してください。

終了時に、実装内容、テスト結果、残課題、次の推奨作業を報告してください。
```

## 「次に何をすべきか」だけ確認する依頼文

```text
実装やファイル変更はまだ行わず、このリポジトリのコード、Git差分、テスト、docs/06_実装、MVP_PLAN.mdを確認してください。現在の進捗、未完了のMVP項目、依存関係、リスクを整理し、次に行う一つの推奨作業と最大2つの代替案を、理由・対象ファイル・完了条件付きで提示してください。推測で完了扱いしないでください。
```
