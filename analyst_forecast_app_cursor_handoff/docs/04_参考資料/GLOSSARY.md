# 用語集

| 用語 | 意味 |
|---|---|
| 分析対象者 | 評価する経済アナリスト、発言者 |
| 予測対象 | 個別株、指数、為替、コモディティ、業種、テーマ等 |
| 分析案件 | ユーザーが指定した一回の調査依頼 |
| 実行ラン | アプリを一回実行した単位 |
| 情報源 | 動画、ブログ記事、X投稿、Web記事等 |
| 発言セグメント | 原文中の話者・位置が特定された発言部分 |
| 予想表明 | ある時点で改めて行われた一つの予想。基本的な件数単位 |
| 予想グループ | 同じ見通しの再表明、修正、反転をまとめた系列 |
| 構成予想 | 複合予想を評価可能な単位へ分解したもの |
| 評価用指標 | 予測対象をPythonで評価するための指数、ETF、銘柄群等 |
| ベンチマーク | 相対成績を比較する市場指数等 |
| 発言日時 | 実際に予想を述べた日時 |
| 公開日時 | 視聴者・読者が予想を確認可能になった日時 |
| 予想精度 | 発言日時基準で見た予測能力 |
| 投資利用成績 | 公開日時後に利用した場合の成績 |
| 早期実現 | 予想された時期より早く方向・価格等が実現した状態 |
| 証拠強度 | 本人直接発言、直接引用、要約等の証拠レベル |
| 調査網羅性 | 調査・取得・処理できた範囲と限界 |
| raw原文 | 取得・入力されたままの変更禁止データ |
| processed原文 | 句読点、段落、話者情報等を付けた派生データ |
| 評価スナップショット | 特定基準日時点の予想進捗・評価状態 |
| 代理指標依存 | テーマ等の評価結果が選択した指数や銘柄群に左右される状態 |
| 後知恵・情報逆流 | 発言後の結果や後発情報を過去時点の対象選定へ使用すること |
| MVP | 最小限の一連動作を確認できる初期版 |
