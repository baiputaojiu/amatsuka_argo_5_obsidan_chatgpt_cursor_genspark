意味判断はAI、再現可能な形式検査・計算・集計はPythonが担当する。Pythonが予測対象の意味を勝手に推測したり、取得不能な価格を補間して事実扱いしたりしない。

## 11. 自動進行ルール

AI出力取込み後、前提が満たされたPython処理を自動的に連続実行する。AIまたはユーザー作業が必要になった時点で停止し、次の作業を説明する。

```text
Pythonが自動実行した処理
次に必要な担当
推奨操作
使用するプロンプト
入力・出力先
代替案
```
