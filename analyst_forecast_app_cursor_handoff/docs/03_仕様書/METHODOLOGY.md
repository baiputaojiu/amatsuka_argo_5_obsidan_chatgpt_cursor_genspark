# 予想認定・評価方法

## 1. 目的

原文から何を予想として採用し、どの市場実績と比較し、どのようにアナリスト能力と現在予想へ反映するかを定義する。

詳細な0～100変換式や総合重みは未決定であり、実データによる技術検証後に固定する。本書では評価項目と意味を確定する。

## 2. 予想認定

| 発言 | 分類 | 正式評価 |
|---|---|---|
| 年末までに日経平均は上昇する | 方向性予想 | 対象 |
| 年末に45,000円になる | 数値・時点予想 | 対象 |
| 利下げなら成長株が上がる | 条件付き予想 | 条件成立時に対象 |
| A社は買い | 投資推奨 | 別区分で対象 |
| 半導体株に上昇余地がある | 弱い方向性予想 | 対象、具体性低 |
| 上昇する可能性もある | 可能性提示 | 原則除外 |
| A社は割安 | 現状分析 | 除外 |
| 上昇も下落もある | シナリオ列挙 | 本命なしなら除外 |
| 昨年の下落は金利が原因 | 過去説明 | 除外 |

「割安なので買い」は投資推奨として対象とする。「割安」だけでは対象にしない。

## 3. 複数シナリオ

- 本命、優先順位、発生確率がある場合は主要予想を評価する。
- 本命以外も補足シナリオとして保存する。
- 本命のない両論併記は的中率へ入れない。
- 確率付きの場合、全確率を保存し、MVPでは最高確率シナリオを主要方向として扱う。
- 確率校正はデータ蓄積後の将来課題。

## 4. 情報源と証拠強度

| レベル | 内容 | 取り扱い |
|---|---|---|
| A | 本人の公式媒体での直接発言 | 正式採用 |
| B | 本人出演動画・インタビューの直接発言 | 正式採用 |
| C | 信頼できる媒体の本人直接引用 | 採用可能、引用範囲明示 |
| D | 記事による要約・言い換え | 参考予想として分離 |
| E | 第三者による紹介 | 原則正式評価から除外 |
| F | 出所・発言者不明 | 除外 |

収集優先順位と証拠強度は別である。YouTube切り抜きの第三者要約より、本人ブログの直接発言を強い証拠とする。

## 5. 発言者推定

話者情報のないYouTube文字起こしは、次を参考に高性能AIが推定する。

- 動画タイトル・説明・チャンネル。
- 出演者情報。
- 呼びかけ、質問、回答、相づち。
- 一人称の経歴・担当分野。
- 発言日時以前の本人確認済み発言や表現。

各セグメントへ話者候補、確信度、根拠、要レビュー状態を付ける。低確信度・重要発言は別AIで再検証する。未解決を無理に本人認定しない。

## 6. 予想表明・グループ・構成予想

### 予想表明

ある時点で改めて行われた予想。的中率の基本件数。

同じ見通しを後日再表明した場合、各表明をその日時・価格から個別評価する。

### 予想グループ

同じ見通しの継続、修正、反転、撤回を関連付ける。再表明の統計的依存や分析品質の重複を確認するために使用する。

### 構成予想

「9月まで上昇し、その後下落」を、上昇、転換、下落に分解する。各部分を評価するが、予想件数は親表明1件とする。

## 7. 再表明と再配布

### 新しい表明

- 後日の動画・記事で改めて同じ予想を述べる。
- 「見方は変わらない」と再確認する。
- 新しい根拠を追加する。
- 目標・期限・条件・方向を変更する。

### 新しい表明にしない

- 動画URLをXで共有しただけ。
- 同じ記事の転載・自動連携。
- 第三者の引用。
- 切り抜き。
- 過去発言を回顧しただけ。

現在の集約では、同じ人物の複数再表明を複数人の票として数えない。

## 8. 予想形式

| 形式 | 例 | 主評価 |
|---|---|---|
| 期限内到達 | 年末までに45,000円 | 期限内に一度でも到達 |
| 時点予想 | 年末時点で45,000円 | 指定時点との誤差 |
| 期間方向 | 今後3か月上昇 | 開始と終了を比較 |
| 期間中状態 | 年内高値圏 | 期間全体の状態 |
| 転換点 | 9月に天井、その後下落 | 転換時期と前後方向 |
| 相対予想 | 半導体株は市場を上回る | ベンチマーク超過 |
| レンジ | ドル円150～155円 | レンジ滞在・終値等 |
| イベント | 年内利下げ | 発生有無・時期 |

## 9. 時期

### 保存する由来

```text
explicit
inferred
system_default
none
```

- `explicit`だけをアナリストの正式な時期精度へ算入する。
- `inferred`と`system_default`でも実績計算はするが参考値とする。
- 時期表現の原文、正規化開始・終了、精度、推定根拠を保存する。

### 期間不明

発言後1、3、6、12か月の結果を保存する。一つの予想に対する観測であり、4件として数えない。

### 発言日時と公開日時

- 発言日時基準：アナリスト自身の予測能力。
- 公開日時基準：利用者が実際に利用できた成績。
- 最終の上昇候補では公開日時基準を重視する。

### 開始価格

MVPは日足を使用する。

- 市場開始前公開：同日始値。
- 市場時間中・終了後・時刻不明：次営業日始値。
- 休場日：次営業日始値。

日中・分足予想は初期版で詳細評価せず、時間粒度不足とする。

## 10. 数値・程度

数値には意味を保存する。

```text
approximate
minimum
maximum
range
exact_target
threshold
```

- 数値明示：実際との誤差を計算。
- 「少なくとも」：下限達成を判定。
- 「最大」：上限との関係を判定。
- 「大幅」「少し」：数値へ勝手に変換しない。
- 定性的予想でも実際の変化率とボラティリティ調整値を表示する。

## 11. 条件付き予想

- 条件不成立は不的中ではなく評価対象外。
- 条件成立後に結果評価を開始する形式を扱う。
- 「利上げし、円高になる」は、利上げ予想と条件後の円高予想へ分ける。
- 「もし利上げなら円高」は、利上げ自体を予想したことにしない。
- 数値条件はPython、曖昧な政策・イベント条件はAIと資料で判定する。
- AND、OR、NOTを保存する。

## 12. 予測対象解決

優先順位は次のとおり。

1. 発言者が予測対象として明示した銘柄・指数等。
2. 発言者が構成銘柄・代表例として明示したもの。
3. 発言日時点で存在した公式指数。
4. 発言日時点で存在したETF。
5. 発言日時点情報から作成した固定バスケット。
6. 適切な候補がなければ定量評価不能。

AIは最大3候補と選定理由を提示し、別AIが以下を検証する。

- 原文での役割。
- 発言日時点の存在。
- 後発分類の混入。
- ティッカー、取引所、通貨。
- テーマとの意味整合。
- 結果がよかった銘柄だけの選択でないこと。

不一致時だけ裁定する。複数候補が妥当ならそれぞれ評価し、結果が依存する場合は注意表示する。

## 13. 情報逆流防止

- `knowledge_cutoff`を発言日時とする。
- 対象解決時に発言後の市場結果をAIへ渡さない。
- 使用資料の公開日・対象基準日を保存する。
- 現在の構成銘柄を過去へ適用しない。
- マッピング確定後に市場実績を取得する。
- マッピングの提案、レビュー、裁定、ハッシュを保存する。

AIが歴史的結果を学習済みである可能性を完全には除けないため、発言日時以前の証拠、独立レビュー、複数代理指標、評価不能を活用する。

## 14. 市場データ

### 取得元

- 株式、ETF、指数、為替：`yfinance`。
- 経済指標：FRED。
- 取得不能：CSV取込み。

### リターン

- 株価方向：現地通貨の分割調整価格。
- 投資推奨：価格リターンと配当込みリターンを分ける。
- 外国資産：現地通貨と円換算を分ける。
- ベンチマーク比較：同期間、同通貨、同リターン基準。
- データ不足時に別指標であることを隠して代用しない。

## 15. 方向評価

- 上昇：終了価格が開始価格より高い場合、単純方向的中。
- 下落：終了価格が開始価格より低い場合、単純方向的中。
- 実際の変化率、期間中最大上昇・最大下落を併記する。
- 資産ごとの差を示すため、発言前ボラティリティに対する変化も計算する。
- 投資推奨は絶対方向とベンチマーク相対方向を分ける。

## 16. 時期・程度評価

- 期間内かどうかの二値判定。
- 予想期間からのずれ日数。
- ずれに応じた連続時期スコア。
- 目標値、変化率、範囲、閾値との誤差。
- 詳細な0～100変換式は技術検証後に固定する。

## 17. 早期実現

- 「年末までに」は早期到達でも完全的中。
- 「年末時点」「12月頃」「12月から」は早すぎる実現を完全的中にしない。
- 最初の実現日、早さ、実現時値、継続日数、予想時点の値を保存する。
- 正式判定と、方向・程度・時期・継続性の部分評価を分ける。
- 早期と期間内の両方で実現しても2件として数えない。

## 18. 評価状態

```text
not_started
active_on_track
active_off_track
active_indeterminate
fulfilled_early
failed_early
expired_hit
expired_miss
condition_pending
withdrawn
superseded
unevaluable
```

同一予想を再評価するたびにスナップショットを保存する。現在予想は原則として未開始、評価中、条件待ちから生成し、早期完了、撤回、置換は除外または別表示する。

## 19. アナリスト能力

評価を次の階層へ分ける。

1. 予想結果：方向、時期、程度、相対成績。
2. 予想品質：対象、方向、時期、数値、条件、確信度、検証可能性。
3. 分析品質：根拠、論理接続、反対要因、リスク、失敗条件。
4. 修正能力：更新理由、撤回、期限延長、反転等。

MVPは1と、構造化項目から機械計算できる2を優先する。3と4はデータを保存し、簡易表示から開始する。

## 20. 現在予想の統合

- 現在有効な見解だけを使用する。
- 同一人物の同一対象・方向・期間は最新見解を代表にする。
- 分野・期間が近い過去成績を優先する。
- 件数が少ない場合は50%付近へ縮小する等の補正を行う予定だが、式は未決定。
- 予想表明ベースと予想グループ調整後の成績を併記する。
- MVPの重みは、方向成績、分野、期間、サンプル、具体性、現在状態、経過時間に限定する。
- 分析品質を初期の重みへ直接使わない。

## 21. 調査網羅性

- 公式チャンネル・公式ブログ等で総数が分かる場合のみ取得率を計算する。
- 一般Web、X、他チャンネル出演等は総数不明を許容する。
- 媒体調査、発見数、原文取得、処理、検証を分ける。
- 検索条件、確認範囲、取得不能理由を保存する。
