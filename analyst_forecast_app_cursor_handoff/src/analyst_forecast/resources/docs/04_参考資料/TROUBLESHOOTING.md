# トラブルシューティング

## 次に何をすればよいか分からない

1. 実行ファイルで「次にすることを表示」。
2. 案件の `NEXT_ACTIONS.md` を開く。
3. Cursorへ「次に何をすべき？」と質問する。
4. `OPEN_ISSUES.md` にブロッカーがないか確認する。

## AI出力を取り込めない

- ファイルが `03_ai_outputs/inbox/` にあるか。
- 指定されたファイル名か。
- JSON以外の説明文が混入していないか。
- 必須項目があるか。
- 原文ファイルへの参照が正しいか。

Pythonが修正用プロンプトを生成した場合は、そのプロンプトだけを実行します。

## 原文引用が見つからない

- AIが句読点を補った `processed` だけを引用していないか。
- `raw`上の該当位置が保存されているか。
- 文字コードや改行差がないか。
- 引用ではなくAI要約になっていないか。

解決しない場合は正式評価へ取り込まず、`needs_review`にします。

## YouTubeの話者を判定できない

- 動画タイトル、説明欄、出演者情報を追加する。
- 前後の会話を広げる。
- 過去の本人確認済み発言を参考資料に加える。
- P06話者推定レビューを実行する。

レビュー後も不明なら `speaker_unresolved` のまま保存し、本人の正式予想には算入しません。

## 市場データを取得できない

1. ティッカー、取引所、通貨を確認。
2. 日付範囲を確認。
3. `yfinance`から再取得。
4. CSV取込み形式をターミナルで確認。
5. CSVを指定先へ置く。

価格をAIに推測させないでください。

## テーマの評価用指標が一致しない

- P11提案とP12レビューを確認する。
- P13裁定を実行する。
- 複数候補が妥当ならすべて評価し、代理指標依存と表示する。
- 適切な候補がなければ `unresolvable` とする。

## 同じ予想が重複している

- 後日の再表明なら別予想表明で正しい。
- 同時転載、リンク共有、切り抜きなら同一表明へ関連付ける。
- P14予想関係整理を実行する。

## 現在予想に古い予想が残る

- 予想期限を確認する。
- 後の撤回・反転・置換が未処理でないか。
- 市場実績と状態を更新する。
- 期間不明予想は12か月で期限切れになる設定を確認する。

## スコアが不自然

- 発言者明示期間とシステム既定期間を混同していないか。
- 「までに」と「時点で」を誤分類していないか。
- 配当込みと株価リターンを混ぜていないか。
- 現地通貨と円換算を混ぜていないか。
- 株式分割処理を確認する。
- 評価用指標のマッピングバージョンを確認する。

## DB更新中に停止した

- 自動バックアップを確認する。
- 処理ログでコミット前か後か確認する。
- 同じ取込みを再実行しても重複しない設計を利用する。
- DBを直接編集せず、復旧メニューを使用する。
