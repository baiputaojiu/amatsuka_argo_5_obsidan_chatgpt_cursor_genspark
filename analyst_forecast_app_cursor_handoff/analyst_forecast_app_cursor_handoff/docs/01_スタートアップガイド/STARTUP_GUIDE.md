# スタートアップガイド

このガイドは、アプリを初めて起動し、最初の分析案件を作成するまでの手順を説明します。実装前のため、コマンド名や画面文言は暫定です。

## 1. 事前に用意するもの

- Windows 11 PC。
- Obsidianと使用するVault。
- CursorまたはChatGPT。両方でもよい。
- インターネット接続。
- 分析したいアナリスト名。
- 必要に応じてYouTube文字起こし。

## 2. 初期設定

初回起動時に、アプリは次を確認します。

```text
Obsidian Vaultの場所
調査フォルダ名
既定のAI実行環境
使用する高性能モデル名
市場データ取得設定
基準通貨（初期値：JPY）
```

調査フォルダの初期値は次とします。

```text
30_Permanent/★アナリスト調査
```

APIキーが必要な場合は環境変数へ設定し、Markdownやログへ書きません。MVPの株価取得は `yfinance` を基本とするため、最初から有料APIは必要ありません。

## 3. アプリ起動

完成版では次の実行ファイルを起動します。

```text
analyst-research.exe
```

開発中はPythonから起動します。

## 4. 新しい案件の作成

メニューから「新しい分析案件を作成」を選び、以下を入力します。

```text
分析対象者
調査開始日
調査終了日
評価基準日
YouTubeを調査するか
ブログを調査するか
Xを調査するか
その他Webを調査するか
特に抽出してほしい予測対象
AI実行環境
```

調査期間の初期値は実行日から過去6か月です。過去実績用と現在予想用には分離しません。

## 5. 自動作成されるもの

- 分析対象者IDと案件ID。
- 案件フォルダ。
- `request.yaml`。
- `status.yaml`。
- `WORKFLOW_STATE.json`。
- `NEXT_ACTIONS.md`。
- 選択媒体に必要なAIプロンプト。
- 原文、AI出力、結果、監査ログの保存先。

## 6. 次の作業を確認

案件作成後、ターミナルは一つの推奨作業を表示します。

```text
次にすること【推奨】
[AI・Cursor]
P01 YouTube情報源探索を実行してください。

プロンプト：...
入力：...
出力先：...
完了後の操作：AI出力を取り込む
```

迷った場合はメニューの「次にすることを表示」を選びます。Cursorでは、案件フォルダを開いて「次に何をすべき？」と質問できます。

## 7. AIプロンプトの実行

### Cursor

1. ターミナルが示したMarkdownを開く。
2. 「依頼文」部分をCursorへ入力する。
3. 指定された入力フォルダを読み込ませる。
4. 指定された出力先へJSONを保存させる。

### ChatGPT

1. ChatGPT版プロンプトを開く。
2. 指定された原文・メタデータを添付する。
3. 「依頼文」を送る。
4. 指定ファイル名のJSONとして保存する。
5. 案件の `03_ai_outputs/inbox/` へ置く。

## 8. AI出力の取込み

実行ファイルから「AI出力を取り込む」を選びます。Pythonが以下を確認します。

- JSON形式。
- 必須項目。
- ID重複。
- 引用が原文中に存在するか。
- 日付形式。
- 参照ファイル。
- 情報期限違反の疑い。

正常ならSQLiteへ登録し、Pythonだけで進められる処理を自動実行します。

## 9. 最初のレポート

少なくとも次が出力されたら、最初の一連動作は成功です。

- `all_forecasts.md`
- `active_forecasts.md`
